# GiziPro 🌱

GiziPro adalah *landing page* modern dan responsif yang dirancang untuk platform analisis kebutuhan gizi cerdas. Proyek ini dibangun untuk kemudahan pengembangan secara *online*, memanfaatkan integrasi langsung antara GitHub dan Vercel.

## 🚀 Fitur

*   **Desain Responsif**: Tampilan yang menyesuaikan dengan mulus di berbagai perangkat (Mobile, Tablet, Desktop).
*   **Skema Warna Khusus**: Menggunakan kombinasi warna Hijau (Utama), Kuning (Aksen), dan Putih (Dasar) yang segar dan sesuai dengan tema kesehatan.
*   **Hero Section**: Ajakan bertindak (*Call to Action*) yang menarik dengan tipografi yang kuat.
*   **Fitur Unggulan**: Kartu informasi dengan efek *hover* yang menampilkan layanan utama (Analisis Gizi, Resep Menu, Status Kesehatan).
*   **Pricing Table**: Desain perbandingan paket akses (Single Pack & Full Pack) dengan *highlight* pada paket terpopuler.

## 🛠️ Teknologi yang Digunakan

*   **HTML5**: Struktur semantik halaman web.
*   **Tailwind CSS**: *Utility-first CSS framework* (diakses via CDN) untuk *styling* yang cepat dan praktis tanpa perlu kompilasi lokal (Node.js/NPM).
